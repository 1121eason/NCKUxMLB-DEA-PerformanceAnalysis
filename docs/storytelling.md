# 資料敘事設計

[回首頁](../README.md) · [完整個案](case-study.zh-TW.md)

這個案例以一條可追問的線索串起資料與管理判斷。原報告已有從明星球員、績效分數到商業價值的故事；公開版將重複轉場合併，加入可重現證據及清楚的模型界線。

| 故事段落 | 讀者正在追問什麼 | 使用證據 | 溝通目的 |
|---|---|---|---|
| 問題 | 打得更好就該領更多嗎？ | 原 PDF 2–3 頁 | 建立具體管理疑問 |
| 情境 | 誰在定義球員價值？ | 5、10–19 頁的利害關係人脈絡 | 讓決策者與價值來源可見 |
| 比較 | 多項表現如何共同評估？ | 23、25 頁的欄位與資料 | 交代資料與分析單位 |
| 反差 | 為何 Stanton 1.000、Freeman 0.731？ | 33、40–42 頁 | 以可核對的反差引出解釋需求 |
| 解釋 | 分數到底代表什麼？ | 原投入產出；新增 LP 重建 | 避免把分數直接當球員好壞 |
| 檢查 | 薪資口徑或假設會改變故事嗎？ | 新增薪資版本與 BCC 診斷 | 讓讀者看到結果的條件 |
| 決策 | 哪些價值還沒有被衡量？ | 43–51 頁與新增研究設計 | 連結商業價值、合約與風險 |

敘事中保留三條界線：原始結果與新增分析分開；數學投影與行動建議分開；商業價值假說與已測得收入分開。讀者可以不同意模型設定，仍能檢查資料及推理的連接是否成立。
